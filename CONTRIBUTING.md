# Contributing

Corrections are the most valuable contribution. If Shopify added a feature, an app was discontinued, or a risk level no longer matches reality, please tell us.

## Reporting an issue

Open an issue with:

- the plugin `slug`,
- what is wrong or missing,
- a link that confirms the change, such as Shopify's changelog, help center or the app's listing.

## Suggesting a new plugin

Include the plugin name and slug, its category, what replaces it on Shopify and why, and a proposed risk level with a one-sentence note.

We prioritise plugins that appear on many WooCommerce stores.

## Pull requests

`data/plugins.json` and `data/plugins.csv` are generated from our internal source and republished on each update. You are welcome to edit them in a pull request; we apply accepted changes to the source so they are not overwritten.
